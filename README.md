# Basic Queries of SQL

Practice queries written while learning SQL Server,
using the AdventureWorks2022 sample database.

## Topics covered
| File | Topic |
|---|---|
| `01_select_from.sql` | SELECT / FROM |
| `02_where.sql` | WHERE (filtering rows) |
| `03_order_by_top.sql` | ORDER BY / TOP |
| `04_in_between_like_null.sql` | IN, BETWEEN, LIKE, AND, OR, IS NULL |
| `05_aggregate_functions.sql` | COUNT, SUM, AVG, MIN, MAX |

## Database
Microsoft AdventureWorks2022 sample database (SQL Server).
The backup file is not included in this repository.
